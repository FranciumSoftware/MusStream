# MusStream
MusStream is a source based music streaming app.
## Concept
It is based on fediverse concepts. You can add your favorite music sources to your feed. It's offers a large selection of musics
that correspond to you. This is a royalty free and ads free music streaming app.
## Installation
To install MusStream, you can download it from the [latest release](https://github.com/FranciumSoftware/MusStream/releases/latest).
### Windows
Download the .exe file from the [latest release](https://github.com/FranciumSoftware/MusStream/releases/latest) and run it.
### Linux
See build instructions
### macOS
See build instructions
### Build from source
Clone the repo: `git clone https://github.com/FranciumSoftware/MusStream.git`

Go to the repo directory: `cd MusStream`

Run the build script: `cargo build --release`

The binary will be located in `target/release/MusStream.exe` (Windows) or `target/release/MusStream` (Linux/macOS).
